# CPU renderer 

A renderer that utilizes the CPU to process and display all on-screen objects by implementing advanced computer graphics algorithms.
Using GLFW and OpenGl texture to draw whatever cpu processes. For mathematical operations, it employs GLM.

## Features
- The whole process is split into stages like graphics pipline.
- It is possible to program vertex and fragment stages
- Text based file format for scenes
- Scene consist of camera, multiple meshes and lights.
